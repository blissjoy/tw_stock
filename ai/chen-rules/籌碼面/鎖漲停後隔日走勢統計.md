# 鎖漲停後隔日走勢統計

- **Rule ID**: R-CHIP-15
- **名稱**: 短線券商鎖漲停後隔日走勢統計
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P06-C1-要命短線客人氣股由多翻空.md`（第6篇第1章「要命短線客 人氣股由多翻空」，p.198-201）
- **解讀**: 書中評為「統計數字最精確、密度最高的一章」，給出全書最完整的回測式統計基準（樣本2,000多筆短線券商進出紀錄）：短線券商鎖漲停後，隔天開高機率**75.7%**，平均開高幅度**+1.91%**，開盤後平均再上攻至當日最高點**+2.04%**（累計約+3.95%相對前收），盤中最低點平均**-0.78%**，隔天平均日內振幅**4.73%**，最後收盤平均僅比前一日**小漲0.7%**（代表開高走低、大幅蒸發漲幅），隔日收黑K或留上影線的機率高達**80%**。機制解釋：短線客靠「強鎖漲停」誘多，隔天散戶追價時短線客早已在盤中高檔出脫，動作不夠快的散戶幾乎全數套牢；短則3~5天、長則數週到數月才能整理完畢，只有1~2成股票能逆勢上揚（通常是因為有投信/長線法人買盤持續湧入，能消化短線客出貨造成的震盪，這類股票反而應該買進）。書中明確提醒：這是2014年前的統計數字，證所稅之後市場結構已改變（短線券商操作頻率下降），若要使用必須用近期資料重新統計，不可直接沿用。
- **可程式化**: 是——「偵測個股鎖漲停日+統計隔日OHLC表現」這個核心邏輯只需要股價資料（已有），完全不需要分點資料，可以立刻重新統計驗證這組數字在近期市場是否還成立。「短線券商占比>80%」「法人買盤較多可能續強」這兩條進階判讀需要分點資料(`broker_chips`)才能做，屬於加強版但非必要。
- **所需資料**: 個股每日OHLC與是否漲停（已有，`stock_prices`表）。加強版（短線券商占比）需要`broker_chips`表（待FinMind付費方案）。
- **計算公式**:
```
function limit_up_next_day_stats(all_stocks, date_range):
    # 找出所有鎖漲停的(stock, date)配對，統計隔日表現分布
    events = [(s, d) for s in all_stocks for d in date_range if is_limit_up(s, d)]
    results = []
    for stock, date in events:
        next_day = next_trading_day(date)
        prev_close = close[stock][date]
        results.append({
            "open_pct": (open_[stock][next_day] - prev_close) / prev_close,
            "high_pct": (high[stock][next_day] - prev_close) / prev_close,
            "low_pct": (low[stock][next_day] - prev_close) / prev_close,
            "close_pct": (close[stock][next_day] - prev_close) / prev_close,
        })
    return summary_stats(results)  # 用近期資料重新統計，比對書中75.7%/1.91%/2.04%/0.78%/4.73%/0.7%這組基準
```
- **參數**: 統計窗口（近期多少年資料重新統計）需自行決定；書中「隔日收黑機率80%」「短線客占比80%」的門檻可作為初始比對基準，但都需要重新驗證時效性。
- **可回測**: 是——這是本清單中資料需求最低、最容易立刻開始的統計驗證項目之一，只需要現有股價資料，不受`broker_chips`瓶頸限制。
- **信心**: 75/100 中高（資料完全就緒、邏輯簡單明確、書中給出精確可比對的統計基準，可程式化程度很高；扣分原因是書中自己承認這組數字時效性存疑，必須先用近期資料重新統計驗證是否還成立，不能直接當成現成規則套用，且目前確實還沒有人寫這段統計程式碼）。
