# 不願拉漲停轉主動拉漲停進場時機規則

- **Rule ID**: R-CHIP-21
- **名稱**: 「不願拉漲停→主動拉漲停」進場時機規則
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P07-C4-凶狠新鉅科主力完美操控.md`（第7篇第4章「凶狠新鉅科 主力完美操控」，p.256-257）
- **解讀**: 書中評為「全書最完整的進場時機示範」。核心判讀：追蹤該股歷史主要買進券商在「漲停日」的買賣方向轉變——(1) **主力初期拒絕拉漲停**：股價被其他人（通常是短線客）拉到漲停，但原本布局的主力券商卻站在賣方（往上賣），代表這根漲停不是主力發動的，「不被祝福的拉抬」股價後續走不遠；(2) **主力轉為主動拉漲停**：同一券商從平盤價一路買到漲停板，代表主力心態已從「布局」轉為「準備作價」，是全書認定「最好的進場時機點」——雖然不會買在最低價，但最有資金效率。新鉅科案例完整展示這個轉折：2012年10月17日拉漲停但主力賣出（判定是短線客小虎隊所為）；2012年12月13日再拉漲停，這次主力主動買到漲停板，之後股價從90元附近展開到127.5元的大波段。
- **可程式化**: 否——需要「該股歷史主要買進券商」在「漲停日」當天的買賣方向與掛單價位，判斷是否「買到漲停板」，這需要`broker_chips`表（單日買賣總量+分點識別，待FinMind付費方案）搭配當日是否觸及漲停的價格資料（已有）；若要精確判斷「買到漲停板」而非「當日淨買超」，理論上還需要類似R-CHIP-12的分價明細，但用`broker_chips`的單日淨買賣方向做簡化版判斷（漲停日該分點淨買超轉正）也可以近似捕捉核心訊號。
- **所需資料**: 個股每日各券商分點買賣張數（`broker_chips`表，待FinMind付費方案）、個股每日是否觸及漲停（已有）、個股歷史主要買進券商名單（需先用`broker_chips`歷史資料統計出來）。
- **計算公式**:
```
function limit_up_trader_stance(stock, main_trader, limit_up_date):
    row = broker_chips[stock][main_trader][limit_up_date]
    net = row.buy - row.sell
    if net < 0:
        return "主力賣出，非主力發動的漲停，走勢難久"
    if net > significant_buy_threshold:
        return "主力主動買到漲停，籌碼收足，最佳進場時機"
    return "無明確訊號"
```
- **參數**: 「顯著買超」的門檻書中沒有給出精確數字，需自行設定並回測（可用該分點過去平均單日買超的倍數作為相對門檻）。
- **可回測**: 否——資料源未到位，無法回測。
- **信心**: 25/100 低（訊號轉折邏輯清楚、案例完整；扣分原因是需要先從`broker_chips`歷史資料統計出「該股歷史主要買進券商」這個前置步驟，資料需求層級比單純的「假外資偵測」等規則更高，且核心資料源本身未到位）。
