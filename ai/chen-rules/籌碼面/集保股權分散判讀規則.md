# 集保股權分散判讀規則

- **Rule ID**: R-CHIP-07
- **名稱**: 集保股權分散表判讀規則（籌碼流向＋身分分類＋股權集中度）
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P02-C2-籌碼流向與集保股權動態.md`（第2篇第2章「籌碼流向與集保股權動態」，p.058-067）
- **解讀**: 書中評為「全書目前最高」評級的一章，因為集保結算所每個月都會公告每檔個股的股權分散資料（15級距，從持有1張以下到1,000張以上），是官方主動公開發布的月頻率資料，取得門檻遠低於分點資料。核心規則有三條：(1) **身分分類**：持有≤20張=散戶、20~800張=中實戶或法人、>1,000張=大股東或主力（800~1,000張書中沒有明確歸類）；(2) **籌碼流向判讀**：持股>1,000張戶數增加+持股≤20張戶數減少=籌碼從散戶流向大股東=股價多半續漲；反之則多半續跌；(3) **股權集中度**：持股1,000張以上集保戶占總體集保庫存數的比重，數字越高代表股權越集中、越好拉抬，若再搭配董監改選/經營權之爭題材，是「股價最飆」的組合（但「董監改選」本身需要額外的公司治理公告/新聞資料源才能判定，見R-CHIP-17）。書中提醒「張數」門檻沒有考慮不同股票股本/股價差異，高價股或小股本股用固定張數可能失真，程式化時應考慮改用占集保庫存比例做標準化。
- **可程式化**: 是——2026-08-09查證發現，這個資料源與核心分類邏輯**本專案其實已經有了**：`src/data/schema.sql`的`holder_shares_distribution`表、`src/data/finmind_client.py`的`fetch_holding_shares_per()`（免費可用，來源是FinMind彙整的`TaiwanStockHoldingSharesPer`，底層資料就是TDCC集保戶股權分散表），這是2026-08-04為黃豐凱籌碼分析法新增的（見`src/indicators/huang_chip_signals.py`的`classify_holder_change()`）。**但黃豐凱版本用的是二分法**（大戶=僅`more than 1,000,001`股一個級距、散戶=另外9個小級距加總的百分比週變化），跟陳家豐這裡的「20/800/1,000張三級距身分分類＋股權集中度百分比＋跟股價方向對照」視角不完全相同——資料源相同，但這條規則本身（20/800/1000張分類、股權集中度單一數值、跟股價趨勢的對照判讀）目前沒有獨立實作在`chen-rules`體系底下，是否要另建一份`chen`專屬的計算函式、還是共用黃豐凱那份並調整門檻，需要之後決定。
- **所需資料**: `holder_shares_distribution`表（本專案已有，FinMind`TaiwanStockHoldingSharesPer`來源，週更新）、股價資料（已有）。
- **計算公式**:
```
function classify_holder_identity(level: str) -> str:
    # 需要把FinMind的17級距(股數)換算成書中20/800/1000張(=股數/1000)的3分類
    shares = parse_level_upper_bound(level)
    lots = shares / 1000
    if lots <= 20: return "散戶"
    if lots <= 800: return "中實戶或法人"
    if lots > 1000: return "大股東或主力"
    return "模糊地帶"

function ownership_concentration(rows_for_date):
    # 股權集中度：持股1000張以上集保戶占總體集保庫存數比重
    return sum(r.percent for r in rows_for_date if parse_level_upper_bound(r.level)/1000 > 1000)

function chip_flow_direction(rows_this_month, rows_last_month):
    whale_change = ownership_concentration(rows_this_month) - ownership_concentration(rows_last_month)
    retail_change = retail_percent(rows_this_month) - retail_percent(rows_last_month)
    if whale_change > 0 and retail_change < 0:
        return "籌碼從散戶流向大股東，股價多半續漲"
    if whale_change < 0 and retail_change > 0:
        return "籌碼從大股東流向散戶，股價多半續跌"
    return "無明確方向"
```
- **參數**: 20張/800張/1,000張三個身分分類門檻為書中明確數字；800~1,000張模糊地帶書中承認未定義。
- **可回測**: 是——`holder_shares_distribution`資料+股價資料都已在本機DB，「籌碼流向方向 vs. 後續股價報酬率」可直接回測，只是目前還沒有人寫這段回測程式碼。
- **信心**: 78/100 中高（資料源已確認完全可用且已在系統中運作，是本書目前查證結果最好的資料源之一；扣分原因是陳家豐這條規則具體的20/800/1000張分類與股權集中度計算，目前實際上還沒有程式碼實作，只是「資料源已就緒、跟既有黃豐凱規則的關係待釐清」，不是「已經在跑」）。
