# 量縮止跌觀察

- **Rule ID**: R-CHIP-03
- **名稱**: 低檔量縮止跌觀察
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P07-C4-凶狠新鉅科主力完美操控.md`（第7篇第4章「凶狠新鉅科 主力完美操控」，p.254）
- **解讀**: 書中原文：「2012年我發現有人默默布局新鉅科時，成交量已萎縮到當年高峰期的10分之1。這其實是市場的常態，高檔時成交量都是大又熱情，等到低檔時成交量小又冷清，代表散戶已經徹底死心，卻也是股價真正落底、主力再度進場布局的好時機。」這是全書唯一給出具體量化倍數（10分之1）的量能觀察規則，邏輯跟朱家泓的「止跌量」概念（見`ai/ebook-summary/`量能章節）方向一致，但陳家豐這裡明確連結到「主力再進場布局」的籌碼面解讀，不只是單純的價格止跌訊號。
  - 書中同一章案例（新鉅科2012年9月起）強調這個訊號通常要搭配「集中度轉紅、特定券商持續吃貨」一起判讀，不是單獨看量縮就進場——作者自己也提醒這是「市場常態」，不是罕見的獨門訊號。
- **可程式化**: 大部分可直接程式化——「萎縮到高峰期10分之1」是明確倍數，只需成交量歷史資料（已有）；唯一的量化門檻缺失是「當年高峰期」的精確定義，書中沒有給出「如何界定前一波高點」的演算法，本專案用固定天數rolling window近似（見下方實作進度的教訓與修正）。
- **所需資料**: 個股每日成交量（`stock_prices`表，本專案已有）。不需要籌碼分點資料，是三個building block中資料需求最低的一個。
- **計算公式**:
```
function volume_washout_signal(stock, t, lookback=240, shrink_ratio=0.10, recent_window=5):
    smoothed = rolling_mean(volume, recent_window)  # 近5日均量代表「現在的量」，避免單日雜訊
    peak = rolling_max(smoothed, lookback)           # 峰值基準用「近5日均量」的rolling max，
                                                        # 不是單日最大量(避免離群值誤導，見下方教訓)
    return smoothed[t] <= peak[t] * shrink_ratio
```
- **參數**: 高峰期窗口240個交易日(`VOLUME_WASHOUT_LOOKBACK`，約1年，書中「當年高峰期」的工程近似值，非精確數字)、萎縮比例10分之1(`VOLUME_WASHOUT_SHRINK_RATIO`，書中明確數字)、近期均量平滑窗口5日(`VOLUME_WASHOUT_RECENT_WINDOW`，工程估計值，避免單日爆量雜訊)。
- **可回測**: 部分可回測——量縮觸發本身可回測，但書中原文强调要搭配集中度/特定券商吃貨才算完整訊號，那部分（分點籌碼）目前無資料來源，無法一併回測驗證完整規則鏈的勝率，只能驗證「量縮」這個子條件單獨出現後的後續表現。
- **信心**: 75/100 中高（書中給出明確的量化倍數(10分之1)且資料需求最低（只需成交量，本專案已有完整資料），可程式化程度高；扣分原因：①「當年高峰期」書中沒給精確演算法，本專案用固定天數rolling window近似，不是精確重現；②本機真實DB實測觸發率偏高(36.5%，見下方實作進度)，鑑別力不算強，作者自己也提醒這是「市場常態」而非罕見訊號，不適合單獨當高信心買進理由）。
