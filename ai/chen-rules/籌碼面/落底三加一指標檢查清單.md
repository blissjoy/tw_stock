# 落底三加一指標檢查清單

- **Rule ID**: R-CHIP-18
- **名稱**: 落底「三＋一」指標檢查清單
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P07-C1-心酸宏達電大股東說再見.md`（第7篇第1章「心酸宏達電 大股東說再見」，p.230-232）
- **解讀**: 書中評為「全書最完整的落底判斷具體方法」，用宏達電(2498)案例整合4種訊號成一套有優先順序的驗證流程：(1) **外資借券放空是否回補**（借券放空需付費、承擔軋空風險，比單純調整持股更具押注意味，是比普通外資買賣超更可信的空頭/回補訊號，見R-CHIP-10對一般外資買賣超可信度的討論）；(2) **關鍵外資/高手券商是否明顯買進**（案例中是美商高盛，且發現「原任職某外資券商高管轉任被投資公司財務長/發言人」這種人事關聯線索，是值得追蹤的關係人網絡）；(3) **集保股權分散表中大股東(持股1,000張以上)持股是否重新增加**（可直接用R-CHIP-07的資料源與邏輯）；(4) **庫藏股宣布，僅作為前3項都成立後的加分確認**——書中明確提醒庫藏股不能單獨作為買進參考，大股東心態不正常時反而可能是製造機會出貨給公司，宏達電案例「宣佈實施庫藏股心理安慰效果大於實質效果」。
- **可程式化**: 部分——第(3)項集保股權分散已有現成資料源(`holder_shares_distribution`表，同R-CHIP-07)可直接程式化；第(1)項外資借券放空餘額需查證資料源（推測與融資融券資料同屬TWSE OpenAPI平台，但2026-07-28查證時swagger摘要沒列出對應端點，需要下載完整swagger.json重新確認，不能斷定不存在）；第(2)項「關鍵外資/高手券商是否買進」需要分點資料(`broker_chips`，待FinMind付費方案)才能判斷特定券商動向；第(4)項庫藏股公告資料源同R-CHIP-28（推測在MOPS，未逐一查證報表代碼）。四項裡目前只有第(3)項可以真正執行。
- **所需資料**: 外資借券放空餘額（資料源待查證，推測TWSE OpenAPI）、關鍵券商/高手券商買賣動向（`broker_chips`表，待FinMind付費方案）、集保股權分散大戶持股（`holder_shares_distribution`表，已有）、庫藏股公告（MOPS，報表代碼待查證）。
- **計算公式**:
```
function bottom_signal_checklist(stock, t):
    signals = {
        "外資借券回補": short_sale_balance_decreasing(stock, t),  # 資料源待查證
        "關鍵券商買進": key_broker_buying(stock, t),  # 待broker_chips
        "大戶持股增加": whale_holding_increasing(stock, t),  # 已可用holder_shares_distribution
        "庫藏股宣布": has_treasury_stock_announcement(stock, t),  # MOPS，待查證
    }
    core_three_met = signals["外資借券回補"] and signals["關鍵券商買進"] and signals["大戶持股增加"]
    return {
        "落底訊號強度": "強" if core_three_met else "部分",
        "庫藏股加分": signals["庫藏股宣布"] and core_three_met,  # 庫藏股必須在前3項都成立才算加分
        "detail": signals,
    }
```
- **參數**: 無明確數字門檻，四項皆為「是否成立」的二元判斷。
- **可回測**: 否——4項訊號裡有3項資料源尚未到位，無法組合回測完整規則，只能單獨回測第(3)項「大戶持股增加」子條件。
- **信心**: 45/100 低中（方法論整合度高、優先順序明確，且第(3)項核心條件的資料源已完全就緒；扣分原因是其餘3項資料源都還在查證或待付費方案階段，完整規則距離可執行還有明顯落差）。
