# 經營權之爭選股公式與3年週期規則

- **Rule ID**: R-CHIP-17
- **名稱**: 經營權之爭選股公式＋董監改選3年週期規則
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P06-C2-經營權之戰鷸蚌相爭趁勢賺.md`（第6篇第2章「經營權之戰 鷸蚌相爭趁勢賺」，p.208-215）
- **解讀**: 核心選股公式：`(公司擁有土地等實質資產) + (即將面臨董監改選) + (市場派股權足以與公司派分庭抗禮，不是公司派一言堂)`。書中額外提出「財務工程攻防戰」機制——公司派可能用海外可轉債(ECB)「自己發自己認」增持股權，市場派則拉抬股價反制（目的是墊高可轉債轉換價、增加公司派增持成本），三陽(2206)案例中市場派成本約24元、股價被拉到60元以上。**最具體可排程的規則是董監改選3年週期**：若前次改選雙方持股差距不大、公司仍具資產價值，題材會在「前次改選年+3」重新發酵，行情可能提前約1年發動（黑松案例：2013年改選後，作者預估2016年改選依舊戰雲密布，行情可能提前2015年展開）。這跟R-CHIP-04「股東會過戶日賣點規則」是同一個故事的兩個時間刻度：3年週期決定「何時該開始關注」，過戶日決定「何時該出場」。操作提醒：布局期至少1年，不宜融資。
- **可程式化**: 部分——「董監改選3年週期」這個時間排程規則邏輯簡單(`下次改選年=前次改選年+3`)，只需要「個股歷次董監改選年份」這一項資料，推測在MOPS股東會/改選公告可查詢，尚未逐一查證確切報表代碼。「土地等實質資產」需要財報資料（同R-CHIP-06，TWSE OpenAPI資產負債表已確認可用但本專案尚未串接）。「市場派股權是否可與公司派分庭抗禮」需要大股東持股結構分析，可部分用`holder_shares_distribution`表近似，但無法區分「公司派」vs「市場派」這種立場對立的持股（集保資料只看得到持股張數分級，看不到持股人的立場/身分）。ECB財務工程攻防戰機制需要公司治理公告資料，未查證。
- **所需資料**: 個股歷次董監改選年份（MOPS，報表代碼待查證）、公司資產狀況/土地持有（財報資料，TWSE OpenAPI已確認可用但未串接）、大股東/市場派持股比例（`holder_shares_distribution`表部分可用，但無法區分派系）、海外可轉債(ECB)發行公告（MOPS重大訊息，未查證）。

- **參數**: 3年週期、提前約1年發動皆為書中明確數字；「持股差距不大」「仍具資產價值」都是定性描述，沒有精確門檻。
- **可回測**: 否——多項關鍵資料源（董監改選年份、公司派/市場派持股區分）尚未到位，無法回測。
- **信心**: 45/100 低中（3年週期規則是書中少見有明確時間表的規則，可排程性強，理應加分；但「市場派vs公司派持股區分」這個核心選股條件本質上需要人工判斷派系立場，籌碼資料本身無法自動區分，且董監改選年份、公司資產等資料源都還沒查證到位，扣分較多）。
