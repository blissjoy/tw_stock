# 減資股第一天效應

- **Rule ID**: R-CHIP-05
- **名稱**: 減資股恢復交易第一天效應
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P05-C2-揪出主力券商梭哈賺主升段.md`（第5篇第2章「揪出主力券商 梭哈賺主升段」，p.180-184）
- **解讀**: 書中評為「全書罕見完全不依賴分點資料、只需股價本身就能程式化」的規則。減資分兩種動機：現金減資（把現金還給股東）、彌補虧損式減資（打消累積虧損、帶轉機意味）。書中給出一個「陽春但有效」的簡化方法：**只看減資後恢復交易第一天的表現**——通常股價不是大好就是大壞，等看到大漲再跳進去也不遲，因為這類上漲不會只做一兩天，會持續一個波段；反之若第一天大跌，代表「利多已提前反應完畢」。書中黑松(1234)反例給出精確算術驗證：減資前股價已提前上漲4元(30→34元)，加上減資本身可拿回現金2.5元利多，合計已達6.5元，遠超過減資本身2.5元的合理利多幅度，恢復交易當天自然要「回吐」，開盤即跌停——這是「利多不能重複反應」的量化說明，值得作為之後「市場提前反應程度」分析的參考範例。更精細的做法是額外驗證「買最多的券商是否具地緣性/是否為贏家券商」(見R-CHIP-26~30)，但即使沒有分點資料，單看第一天股價表現也是一個可獨立成立的規則。
- **可程式化**: 部分——「偵測減資恢復交易日+觀察第一天表現」這個核心觸發邏輯完全可程式化，只需要股價資料（已有）；唯一缺口是「個股減資公告與恢復交易日期」這個資料源。2026-08-09已用`src/data/mops_client.py`透過MOPS的`/mops/api/redirectToIRB`（`fileNoOfIRB=IRB160`，公司增減資表）抓到「哪些股票哪個月辦理增減資」，資料已存進本機DB的`mops_capital_changes`表（見`ai/PLAN.md`2026-08-09「MOPS增減資紀錄接進個股明細」記錄），但這份報表只有「公司代號+名稱+年月」，**沒有「恢復交易日期」這個關鍵欄位**——恢復交易日通常會比公告晚幾週到幾個月，不能直接假設等於公告當月。要嘛比對`stock_prices`表自己抓「交易一段時間中斷後又重新出現報價」的那一天當作恢復交易日的代理指標，要嘛找MOPS其他報表（IRB系列其餘代碼還沒逐一實測）。
- **所需資料**: 個股減資恢復交易日期（尚未有直接資料源，需自行從`stock_prices`交易中斷/恢復的模式推斷，或找MOPS對應報表）、減資類型(現金減資/彌補虧損式減資，MOPS應該有但未查證欄位)、恢復交易當天與前一交易日收盤價。
- **計算公式**:
```
function capital_reduction_first_day_signal(stock, resume_date):
    prev_close = close[last_trading_day_before(resume_date)]
    first_day_close = close[resume_date]
    first_day_return = (first_day_close - prev_close) / prev_close
    if first_day_return > threshold_up:
        return "大漲，主力介入可能性高，可能持續一波段"
    elif first_day_return < threshold_down:
        return "大跌，利多已提前反應完畢，不宜介入"
    return "表現平淡，不具明確訊號"

function excess_reaction_check(stock, announce_date, resume_date, cash_back_per_share):
    # 黑松案例的「利多不能重複反應」驗證邏輯
    pre_announcement_runup = close[announce_date] - close[announce_date - lookback_days]
    total_priced_in = pre_announcement_runup + cash_back_per_share
    return total_priced_in > cash_back_per_share  # True代表提前過度反應，恢復交易當天可能回吐
```
- **參數**: 大漲/大跌門檻書中沒有給出精確百分比（只用「不是大好就是大壞」的定性描述），需自行設定並回測，可考慮用是否觸及漲跌停作為初始門檻。
- **可回測**: 部分——一旦有恢復交易日資料即可直接回測「第一天表現→後續波段報酬率」的關係；目前卡在恢復交易日資料源，尚未能回測。
- **信心**: 70/100 中高（書中邏輯清楚、資料需求原則上極低，且黑松反例提供了少見的精確算術驗證範例；扣分原因是「恢復交易日期」這個唯一必要欄位目前確實還沒有直接資料源，且「大漲/大跌」門檻書中完全沒給數字）。
