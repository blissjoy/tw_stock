# 股價表態仲裁元原則

- **Rule ID**: R-CHIP-14
- **名稱**: 股價表態仲裁元原則
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P05-C3-破解主力手法狡兔三窟操控.md`（第5篇第3章「破解主力手法 狡兔三窟操控」，p.193-194）
- **解讀**: 書中評為「貫穿全書的元方法論」，跟其他規則不同，這不是一個「觸發即報」性質的訊號，而是一個**回測/驗證框架的核心原則**：當多個籌碼訊號互相矛盾時（例如主力買、投信賣），不糾結哪個訊號更可信，而是看事後股價實際走向，跟隨「贏的那一方」。中石化案例：市場派買、投信賣，結果股價跟著市場派漲，證明投信這次操作不具參考性；書中也提醒一種例外——公司籌碼不夠流通時，公司派可能透過交易轉帳給市場派，雙方聯手作價，此時「大咖對大咖」的矛盾其實是假矛盾。這個原則應該作為本專案設計任何籌碼類規則回測驗證流程的核心方法論：訊號的可信度應該用「歷史上跟隨這個訊號的勝率」來衡量，而不是預設某類法人/主力天生更可信。
- **可程式化**: 部分——這不是一個可以獨立觸發的訊號規則，而是**應該內建進所有籌碼規則的回測評分邏輯裡**的方法論：當兩個或以上訊號同時出現且方向相反時，用「事後N天股價報酬率」判定哪個訊號「贏了」，並據此調整該訊號來源在類似情境下的可信權重。這需要先有多個獨立訊號來源（機構買賣超、主力券商動向等）才能真正發揮作用，目前本專案的`analyze_chip_signals()`（`src/presentation/stock_detail_data.py`）已經同時顯示多條籌碼訊號，但還沒有「訊號矛盾時看事後股價表態」這種自動仲裁/加權機制。
- **所需資料**: 多個獨立籌碼訊號來源（現有的三大法人、融資、量縮等訊號已有部分）、股價（已有）。
- **計算公式**:
```
function signal_arbitration(signal_a_direction, signal_b_direction, stock, t, horizon_days=10):
    if signal_a_direction == signal_b_direction:
        return None  # 訊號一致，不需要仲裁
    future_return = (close[t + horizon_days] - close[t]) / close[t]
    winner = signal_a_direction if (future_return > 0) == (signal_a_direction == "buy") else signal_b_direction
    return winner  # 事後判定哪一方訊號較準確，可用於累積該訊號來源的歷史準確度統計
```
- **參數**: 事後驗證的觀察窗口(`horizon_days`)書中沒有給精確天數，需自行決定並回測。
- **可回測**: 是——這個原則本身不需要新資料源，只需要既有的多個訊號+股價資料即可回測「矛盾情境下跟隨哪一方訊號的歷史勝率較高」，是本清單中少數不受`broker_chips`瓶頸限制、隨時可以開始實作的項目之一，但目前還沒有人寫這段程式碼。
- **信心**: 60/100 中（方法論的普適性與重要性在書中被明確強調為核心原則，且不依賴任何新資料源，理應可以較快實作；扣分原因是這不是一條「規則」而是一個「回測框架設計原則」，需要先決定要用哪些既有訊號來源組合仲裁，目前還停留在概念層次，沒有具體的實作規劃）。
