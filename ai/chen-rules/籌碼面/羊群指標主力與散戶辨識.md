# 羊群指標主力與散戶辨識

- **Rule ID**: R-CHIP-31
- **名稱**: 羊群指標／主力vs.散戶辨識（掛單分散度）
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P02-C1-想賺錢別跟著羊群走.md`（第2篇第1章「想賺錢 別跟著羊群走」，p.046-057）
- **解讀**: 散戶是市場反指標的兩個原因：交易心理素質不同（散戶想便宜買、想賣更高，容易「一買就跌、一賣就漲」，是「逆選擇」概念的通俗表達）、市場資訊不對稱（5層資訊金字塔，一般投資大眾最落後）。**「羊群指標」的核心判斷原理**（本章最重要的方法論揭露）：用「掛單/成交的券商分散度」區分主力vs散戶——散戶交易分散在全省各家券商，呈現高度分散、去中心化的分點分布；主力/大戶交易集中在少數幾家券商下單，呈現高度集中的分點分布。理論上可計算「單一股票每日成交量在各券商分點間的集中度指標」（如Herfindahl指數，或前N大分點佔比，這正是R-CHIP-11「集中度指標」的計算基礎，兩者其實是同一套底層邏輯的不同應用視角）來估計主力vs散戶行為。背離判讀規則：主力一路加碼+羊群指標一路減碼＝籌碼持續從散戶流向主力＝後續股價易漲難跌；反之則不樂觀。案例顯示主力吃貨階段常伴隨「價跌量縮」（散戶想低接卻接不到量），出貨階段則利多消息見報頻率增加、吸引散戶追高接最後一棒。
- **可程式化**: 否——跟R-CHIP-11「集中度指標」使用完全相同的底層資料需求：個股每日各券商分點的買賣張數明細（`broker_chips`表，待FinMind付費方案），且書中沒有給出「多少家券商算分散」「掛低接單的『低』是相對現價低多少」等具體門檻，需自行設計並回測。「主力吃貨階段價跌量縮」這個量價概念子條件，理論上不需要分點資料就能用現有股價/成交量資料驗證，可以優先跟`ai/zhu-rules/量價`分類下的既有規則對照，看是否已有涵蓋類似概念的規則可以直接借用。
- **所需資料**: 個股每日各券商分點買賣張數（`broker_chips`表，待FinMind付費方案）、股價與成交量（已有，用於「價跌量縮」子條件）。
- **計算公式**:
```
function herd_indicator(stock, date):
    # 與R-CHIP-11集中度指標共用同一份底層計算，只是解讀角度相反：
    # 集中度高=主力行為；集中度低(分散)=羊群(散戶)行為
    return 1 - concentration_hhi(broker_chips[stock][date])  # 待broker_chips，數值越高代表越分散(散戶)

function herd_divergence_signal(stock, t, lookback=20):
    main_force_trend = trend_of(institutional_or_broker_net_buy(stock, t, lookback))
    herd_trend = trend_of(herd_indicator(stock, t, lookback))
    if main_force_trend == "加碼" and herd_trend == "減碼":
        return "籌碼從散戶流向主力，易漲難跌"
    if main_force_trend == "減碼" and herd_trend == "加碼":
        return "籌碼從主力流向散戶，不樂觀"

function accumulation_volume_pattern(stock, t):
    # 不需要分點資料，可先獨立驗證這個子條件，並跟ai/zhu-rules/量價既有規則對照
    return is_price_down_volume_shrinking(stock, t)  # 已有股價/成交量資料
```
- **參數**: 「多少家券商算分散」「掛低接單的相對價差」書中均未給出量化門檻，需自行設計並回測。
- **可回測**: 部分——「主力吃貨階段價跌量縮」子條件不需要分點資料，理論上現在就能用既有股價/成交量資料回測（若`ai/zhu-rules/量價`已有類似規則可直接借用比對）；完整的「羊群指標vs主力籌碼背離」規則仍需`broker_chips`，尚無法回測。
- **信心**: 30/100 低（方法論是全書首次具體回答「如何從分點資料辨識散戶」的關鍵突破，且跟R-CHIP-11集中度指標共用底層邏輯、可以合併實作降低邊際成本；但扣分原因是核心資料`broker_chips`未到位，且多項具體門檻書中完全沒給數字，只有「價跌量縮」子條件可以獨立於分點資料先行驗證）。
