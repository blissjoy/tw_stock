# 知名人物型主力辨識法

- **Rule ID**: R-CHIP-29
- **名稱**: 知名人物型主力辨識法（同一組券商同時布局多股）
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P03-C4-知名人物型跟緊利潤高.md`（第3篇第4章「知名人物型 跟緊利潤高」，p.114-120）
- **解讀**: 5大主力分類之一，全書程式化難度最高、最需謹慎看待的一章——本質是「已知真實姓名的市場名人+其慣用券商分點」這種需要新聞/耳語驗證的人工知識，不是能從價量或分點資料自動推導的規則。書中列出盧燕賢（傳產股）、林滄海（電子股）兩位案例人物及其推測慣用券商，但**明確揭露重大反向風險——「偽海哥單」**：知名主力慣用券商一旦公開報導，會被其他次級主力刻意模仿下單製造假訊號，任何「券商=知名人物」對照表都會隨時間失效或被污染，不能當靜態規則長期沿用，必須有持續驗證機制。書中提供一個**不需要預先知道身分的通用方法**：若同一組券商持續在不同時間點布局完全不同的股票（黑松→泰豐→統一案例），巧合一次可能是巧合，巧合兩次以上就能確定是同一組操盤團隊——先用這個統計特徵標記「疑似同一組操盤團隊」，之後才用新聞/公告驗證身分，這比「先知道是誰、再回頭找慣用券商」的方向更適合程式化。
- **可程式化**: 否——「同一組券商同時布局多股」這個通用偵測方法邏輯本身不複雜，但需要「個股×券商×時間」的交易明細資料（`broker_chips`表，待FinMind付費方案），且需要定義「同一時間點」的時間窗口大小、以及多少檔股票同時出現才算「不是巧合」的統計門檻，書中沒有給出量化標準。「券商=知名人物」的具體對照表本質是人工知識，且書中已明確警示會被模仿污染，即使做出來也需要持續人工驗證維護，不建議當作可自動信賴的靜態規則長期使用。
- **所需資料**: 個股×券商×時間的交易明細（`broker_chips`表，待FinMind付費方案）、（人工維護的知名主力身分對照表，僅供參考，需持續驗證更新，不建議自動化信賴）。
- **計算公式**:
```
function detect_coordinated_broker_group(broker_set, time_window_days=30, min_stocks=2):
    # 偵測「同一組券商」是否在不同時間點反覆同時布局不同股票
    coordinated_events = []
    for window_start in all_time_windows(time_window_days):
        stocks_bought_together = [
            stock for stock in all_stocks
            if all(net_buy(stock, tr, window_start, time_window_days) > 0 for tr in broker_set)
        ]  # 待broker_chips
        if len(stocks_bought_together) > 0:
            coordinated_events.append((window_start, stocks_bought_together))
    distinct_stocks = set(s for _, stocks in coordinated_events for s in stocks)
    if len(distinct_stocks) >= min_stocks:
        return "疑似同一組操盤團隊，建議標記追蹤", distinct_stocks
```

- **可回測**: 否——資料源未到位，無法回測。
