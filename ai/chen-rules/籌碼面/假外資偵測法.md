# 假外資偵測法

- **Rule ID**: R-CHIP-09
- **名稱**: 假外資偵測法（雙資料源交叉比對）
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P04-C1-解迷思外資中看不中用.md`（第4篇第1章「解迷思 外資中看不中用」，p.136-141）
- **解讀**: 書中評為「全書唯一一套用兩個獨立公開資料源交叉比對來偵測造假的完整可程式化方法」。3大法人每日買賣超統計(官方統計，來源明確為「來自海外的資金」)照理應該跟個股外資券商分點的買賣情況同調，但可能出現兩種不同調情況：情況①3大法人統計有外資買進，但外資券商分點完全查不到對應下單紀錄（可能是資金來自海外、但透過國內券商國際部/法人部下單，或本國主力在外資券商分點下單製造假象）；情況②3大法人統計沒有外資買賣紀錄，但外資券商分點卻有下單（可能是國內自然人在外資券商開戶，對政府機構屬於國內資金不需揭示）。書中精誠(6199)、農林(2913)案例都是情況①的真實破案案例，農林案例後續在R-CHIP-13（換券商出貨/資金轉移追蹤）中被證實是盧燕賢迪化幫從黑松出脫後轉戰的資金。
- **可程式化**: 部分——3大法人每日買賣超統計本專案已有(`institutional_investors`表)，比較邏輯本身是簡單的差異比對；缺口在於「個股外資券商分點買賣明細」需要`broker_chips`表(FinMind付費方案，同R-CHIP-08)。沒有分點資料就無法判斷「3大法人有外資、但分點沒有」這種不同調，也就無法真正執行假外資偵測，目前只能算「一半資料已就緒」。
- **所需資料**: 3大法人每日買賣超（`institutional_investors`表，已有）、個股外資券商分點買賣明細（`broker_chips`表，待FinMind付費方案）。
- **計算公式**:
```
function fake_foreign_investor_flag(stock, t):
    official_foreign_net = institutional_investors[stock][t].foreign_net  # 已有
    foreign_broker_net = sum(row.buy - row.sell
                              for row in broker_chips
                              if row.stock_id == stock and row.date == t
                              and is_foreign_broker(row.securities_trader_id))  # 待broker_chips
    if abs(official_foreign_net) > threshold and abs(foreign_broker_net) < threshold_low:
        return "情況①：3大法人有外資買賣，分點沒有對應紀錄，疑似假外資"
    if abs(official_foreign_net) < threshold_low and abs(foreign_broker_net) > threshold:
        return "情況②：分點有外資券商下單，但3大法人統計沒有，疑似國內資金借外資通路"
```
- **參數**: 「不同調」的門檻書中沒有給出精確數字，只用案例定性描述（「完全沒看到」「明顯」），需自行設定並回測。
- **可回測**: 否——分點資料未到位，無法回測。
- **信心**: 40/100 低中（書中方法論邏輯清晰、雙資料源交叉驗證的示範完整，理應給較高分數；但實際卡在`broker_chips`需要付費方案，且哪些券商屬於「外資券商」這個分類本身`securities_traders`表目前也沒有標記，還需要額外整理，扣分）。
