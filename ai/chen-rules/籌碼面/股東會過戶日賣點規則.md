# 股東會過戶日賣點規則

- **Rule ID**: R-CHIP-04
- **名稱**: 股東會最後過戶日賣點規則
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P07-C3-老牌中石化董監戰抬行情.md`（第7篇第3章「老牌中石化 董監戰抬行情」，p.246-249）
- **解讀**: 書中評為「全書最精確、最可直接程式化的單一時間點規則」。經營權之爭/董監改選題材的股票，主力布局的目的是拿到足夠股權在股東會改選席次；股權統計只算到「股東會最後過戶日」為止，過戶日之後再買賣股票都不影響改選結果，所以**主力一旦過了過戶日就沒有理由續抱，一開始賣就會賣得又急又深**。中石化案例：盧燕賢團隊布局2年、40萬張持股均價約20元，2012年3月過戶日之後開始出脫，投資人若看到過戶日後出現異常放量賣壓，應立即跟著出場。這條規則跟R-CHIP-17「董監改選3年週期規則」是同一個故事的兩個時間刻度：3年週期決定「何時該開始關注」，過戶日決定「何時該出場」。
- **可程式化**: 部分——「過戶日之後N個交易日內偵測異常放量下跌」這個觸發邏輯本身完全可程式化，且不需要分點資料，只需股價/成交量（本專案已有）；唯一卡住的是「該股票這次股東會/董監改選的最後過戶日期」這個日期本身的資料來源尚未確定。書中推測在公開資訊觀測站(MOPS)的股東會公告或停止過戶期間公告，2026-08-09已確認MOPS的`/mops/api/redirectToIRB` API本身可透過`src/data/mops_client.py`存取(見`ai/chen-rules/籌碼面/`其他規則的MOPS存取說明)，但「過戶日」對應哪個`fileNoOfIRB`報表代碼還沒查證，目前只確認了`IRB160`(公司增減資表)可用。另外「經營權之爭題材」本身的判定（哪些股票有這個題材）也還沒有資料源，見R-CHIP-17。
- **所需資料**: 個股股東會最後過戶日期（MOPS，具體報表代碼待查證）、該股是否為經營權之爭/董監改選題材（見R-CHIP-17，同樣待查證）、股價與成交量（本專案已有）。
- **計算公式**:
```
function post_registration_selloff_signal(stock, record_date, t, window=5, volume_multiple=1.5, decline_pct=-0.03):
    # record_date: 股東會最後過戶日
    if t - record_date not in [1, window]:
        return None
    recent_volume = avg(volume[record_date+1 : t])
    baseline_volume = avg(volume[record_date-20 : record_date])
    price_change = (close[t] - close[record_date]) / close[record_date]
    if recent_volume > baseline_volume * volume_multiple and price_change < decline_pct:
        return "過戶日後異常放量下跌，停利/避險訊號"
```
- **參數**: 過戶日後觀察窗口（書中未給精確天數，暫估5個交易日內，需回測校準）、放量倍數門檻與跌幅門檻皆為工程估計值，書中只有定性描述「異常放量賣壓」，沒有給出量化門檻。
- **可回測**: 部分——一旦取得過戶日資料，觸發邏輯本身可直接回測；但因為過戶日資料源尚未確定，目前完全無法回測。
- **信心**: 70/100 中高（書中對這條規則的邏輯與資料需求描述得非常精確、明確評為全書資料需求最低的規則，理應給高分；扣分原因是唯一需要的「過戶日」資料源至今仍未查證到位，且「異常放量」的量化門檻書中完全沒給，這兩點都還是空白，不能算是已經可執行的規則）。
