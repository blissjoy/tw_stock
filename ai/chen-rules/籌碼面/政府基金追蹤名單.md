# 政府基金追蹤名單

- **Rule ID**: R-CHIP-24
- **名稱**: 政府基金追蹤名單（8大行庫代理指標）
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P04-C3-護盤手政府基金觀全球.md`（第4篇第3章「護盤手 政府基金觀全球」，p.150-151）
- **解讀**: 觀察政府基金是否進場，主要看8大行庫的下單進出狀況，其中兆豐金、華南永昌、第一金因民間證券業務比重高、訊號稀釋，建議排除，優先觀察**台灣金、土銀、合庫金、彰銀、台企銀**這5家。這跟前面章節「地緣關係辨識公司派」「特定券商辨識高手/贏家」是同一種方法論的延伸：用「特定機構關聯的下單管道」作為該機構身分的代理指標。書中2011年歐債風暴「陳沖防線」案例，5大行庫確實明顯買進+隔2天繼續買，成功守住7148低點。限制：政府基金只買大型權值股，只適合有耐性、長線布局權值股的投資人跟單；且「8大行庫」完整正式名單書中沒有列全（只列出排除的3家+建議追蹤的5家），需要另外查證。
- **可程式化**: 否——需要這5家行庫的每日券商分點下單進出狀況，即個股×券商分點的交易明細(`broker_chips`表，待FinMind付費方案)，才能追蹤這幾家券商在特定股票(尤其是台灣50成分股/大型權值股)上的買賣動向。
- **所需資料**: 台灣金、土銀、合庫金、彰銀、台企銀這5家券商分點的每日買賣明細（`broker_chips`表，待FinMind付費方案）、8大行庫完整正式名單（書中未列全，需另外查證）。
- **計算公式**:
```
GOV_FUND_PROXY_BROKERS = ["台灣金", "土銀", "合庫金", "彰銀", "台企銀"]  # 需對應到securities_traders的實際分點ID

function government_fund_activity(stock, t):
    net_buy = sum(broker_chips[stock][tr][t].buy - broker_chips[stock][tr][t].sell
                  for tr in GOV_FUND_PROXY_BROKERS)  # 待broker_chips
    return net_buy
```
- **參數**: 5家追蹤券商名單為書中明確給出；完整8大行庫定義需額外查證，不影響核心追蹤邏輯（書中已直接給出建議追蹤的5家）。
- **可回測**: 否——資料源未到位，無法回測。
- **信心**: 25/100 低（追蹤名單本身明確具體，方法論簡單直接；扣分原因是需要的分點資料未到位，且這套方法的適用範圍書中自己也承認有限——只對大型權值股有意義，對本專案偏好的中小型股操作參考價值不高）。
