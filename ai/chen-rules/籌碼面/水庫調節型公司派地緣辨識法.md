# 水庫調節型公司派地緣辨識法

- **Rule ID**: R-CHIP-27
- **名稱**: 水庫調節型（公司派）地緣辨識法
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P03-C2-水庫調節型銀彈充足.md`（第3篇第2章「水庫調節型 銀彈充足」，p.102-107）
- **解讀**: 5大主力分類之一，通常是公司大股東（公司派）。手中持有大量股票超長期布局，股價偏低慢慢買、走高慢慢賣，如同水庫調節，永遠握有籌碼。辨識方法：公司派通常就近選擇下單券商（尤其中南部上市櫃公司地緣性特別明顯），若交易該公司獲利較豐厚的券商跟公司總部同區域，可推測是公司派下單處(正新/鉅橡/可成案例)。重要洞察——**「賣老股」辨識訊號**：若某地緣關係券商過去長期沒有明顯買進紀錄(代表早已持有的舊倉位)，卻突然大量調節賣出，代表公司派大股東認定目前是長線高點、連老本都要調節，這比一般調節訊號更強(可成案例驗證)。分類邊界：跟股價維護型的區別是**交易頻率**——水庫調節型做大波段、頻率低；股價維護型頻繁進出。公司派不追求買最低賣最高，可能越買越跌、越跌越買，散戶子彈不夠容易先套牢下車。
- **可程式化**: 部分——地緣性判定的前兩項資料（公司總部地址、券商分點地址）都是公開資訊、容易取得（`securities_traders`表已有券商地址欄位，公司地址目前本專案未串接但屬於低難度基本資料）；第三項「該分點在此股票的損益豐厚」與「賣老股」訊號的「過去長期無買進紀錄」判斷，都需要`broker_chips`表（待FinMind付費方案）。地緣性配對本身可以先做（不需要分點資料，只需公司地址+券商地址比對），是這條規則裡可以立即開始的部分。
- **所需資料**: 公司登記地址/總部所在地（本專案未串接，屬公開低難度資料）、券商分點地理位置（`securities_traders`表已有address欄位）、該券商分點交易該股票的損益與歷史買賣紀錄（`broker_chips`表，待FinMind付費方案）。
- **計算公式**:
```
function geographic_match(stock, trader):
    company_region = get_company_hq_region(stock)  # 待補公司地址資料
    trader_region = get_trader_region(trader)  # securities_traders.address已有
    return company_region == trader_region

function is_selling_old_position(stock, trader, sell_date, history_years=2):
    history = broker_chips[stock][trader][sell_date-history_years*365 : sell_date]  # 待broker_chips
    no_recent_buying = all(r.buy == 0 for r in history)
    large_sell = broker_chips[stock][trader][sell_date].sell > significant_volume_threshold
    return no_recent_buying and large_sell  # True = 賣老股，長線高點強訊號

function trading_frequency_classification(stock, trader, period):
    trading_days = count_trading_days(stock, trader, period)  # 待broker_chips
    return "水庫調節型(頻率低)" if trading_days / period_length < low_frequency_threshold else "股價維護型(頻率高)"
```
- **參數**: 地緣性判定門檻無需額外參數（同區域即符合）；「頻率不高/時間拉很長」vs「進出頻繁」的次數門檻書中未給，需自行定義。
- **可回測**: 部分——地緣性配對子條件（公司地址vs券商地址）一旦補上公司地址資料即可回測；「賣老股」與交易頻率分類需要`broker_chips`，暫無法回測。
- **信心**: 40/100 低中（地緣性判定邏輯簡單且資料需求相對單純，是這條規則裡可以優先做的部分；但「賣老股」這個書中信心最高的線索，以及完整的頻率分類，都還需要`broker_chips`才能實作，扣分較多）。
