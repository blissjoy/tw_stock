# 外資訊號有效性條件

- **Rule ID**: R-CHIP-10
- **名稱**: 外資訊號有效性條件（權值股不可信、中小型股可信）
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P04-C1-解迷思外資中看不中用.md`（第4篇第1章「解迷思 外資中看不中用」，p.130-136）
- **解讀**: 書中核心迷思澄清：外資買賣≠可靠的個股多空指標，因為外資買賣台股常常和「看好/看壞該股」無關，而是(1)指數權重調整、(2)期貨套利策略（在國外放空台指期、現股倒貨壓低指數獲利）、(3)全球跨市場布局這三個結構性原因造成的，且外資內部本身「多角多腳」，不同外資機構操作邏輯互不相同，同一天A外資買、B外資賣都很常見。但書中給出一個明確的可信範圍：**外資訊號的有效性跟該股是否為權值股成反比**——中小型股/非權值股不會被外資拿來做策略性套利/權重調整，若外資持續買進代表確實經過深入研究、長線布局，可信；權值股/大型股的外資買賣受上述3個結構性因素干擾，不宜直接採信，此時應改看集中度指標（R-CHIP-11）。
- **可程式化**: 是——3大法人買賣超本專案已有(`institutional_investors`表)，唯一需要的額外資料是「該股是否為權值股/大型股」的分類，可用市值或是否納入台灣50/中型100指數成分股來近似判定，這是常見且容易取得的公開資訊（本專案目前尚未直接串接市值資料，但可從股本×股價估算，或另外抓取指數成分股名單）。
- **所需資料**: 3大法人每日買賣超（`institutional_investors`表，已有）、個股是否為權值股/大型股（用市值或指數成分股名單分類，本專案尚未直接有這個欄位，需另外估算或串接）。
- **計算公式**:
```
function foreign_signal_reliability(stock, t):
    market_cap = shares_outstanding[stock] * close[stock][t]  # 需要股本資料，本專案尚未串接
    if market_cap < mid_cap_threshold:  # 或改用「是否為台灣50/中型100成分股」判斷
        foreign_streak = institutional_investors[stock].foreign_buy_streak(t)
        return "可信" if foreign_streak >= min_streak_days else "訊號不足"
    else:
        return "權值股，外資訊號不可採信，改看集中度(R-CHIP-11)"
```
- **參數**: 「中小型股」的市值門檻書中沒有給出精確數字，只用「是否為權值股」定性描述，需自行設定（例如是否納入台灣50/中型100成分股）並回測。
- **可回測**: 部分——3大法人買賣超資料已有，若用「是否為台灣50成分股」代替市值分類，這個近似版本理論上可直接回測；若要用真實市值分類，則需先補上股本/市值資料。
- **信心**: 65/100 中（核心邏輯清楚、外資買賣資料已有，可程式化程度不低；扣分原因是「權值股/中小型股」的分類門檻書中沒給精確定義，本專案也尚未有現成的市值/指數成分股資料可直接使用，需要額外補資料源才能真正跑起來）。
