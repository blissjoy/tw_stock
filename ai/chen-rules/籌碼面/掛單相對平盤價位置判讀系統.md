# 掛單相對平盤價位置判讀系統

- **Rule ID**: R-CHIP-12
- **名稱**: 掛單相對平盤價位置判讀系統
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P05-C1-摸透主力心態抓住漲勢起點.md`（第5篇第1章「摸透主力心態 抓住漲勢起點」，p.166-173）
- **解讀**: 書中評為「可能是全書方法論最精細的一節」，也是全書資料顆粒度需求最細的規則——需要「分價量明細」（intraday委託/成交在各價位的張數分布，並需知道當日平盤價作基準）。核心是一套對稱的判讀系統：**賣方**——賣盤只掛在平盤價之上＝分批出貨初期，危險性低（有人想追價就賣給他，股價通常還會在高檔震盪）；賣盤擴散到平盤價之下也掛＝強烈危險警訊（籌碼快賣完或已知利空，應迅速出脫甚至反手做空）。**買方**（鏡射對稱）——買盤只掛在平盤價之下＝還在吃貨階段，籌碼未收足，股價不易大漲；買盤擴散到平盤價之上/甚至漲停價＝主力主導拉抬確認，是最佳進場時機。同一套系統可應用在三個場景：一般主力進出判讀、技術面突破真偽判斷（技術面突破但主力掛單卻站賣方＝假突破警訊，是全書對「騙線」問題最具體的解法）、庫藏股執行心態判斷。
- **可程式化**: 否——需要的「分價量明細」比`broker_chips`表（單日買賣總量，FinMind`TaiwanStockTradingDailyReport`）更細一層，需要「當日委託/成交在各價位的分布」，這種intraday逐筆/逐檔資料目前完全不清楚是否能從公開來源取得，是否僅限iGold等商用工具才有，本專案完全沒有查證過這個資料源，甚至比`broker_chips`(待FinMind付費方案解鎖)更難，是全書資料需求最高的規則之一。
- **所需資料**: 個股單一券商分點的分價量明細（intraday委託/成交在各價位的張數分布）、當日平盤價（已有，等於前一交易日收盤價）——分價量明細本身資料源完全未知，需優先查證是否存在公開管道。
- **計算公式**:
```
function order_position_signal(stock, trader, date, reference_price):
    # 需要 price_volume_detail(stock, trader, date) 這種資料，本專案目前沒有
    sell_orders = price_volume_detail(stock, trader, date, side="sell")
    buy_orders = price_volume_detail(stock, trader, date, side="buy")

    if all(p >= reference_price for p, v in sell_orders):
        sell_state = "只在平盤上，分批出貨初期"
    elif any(p < reference_price for p, v in sell_orders):
        sell_state = "擴散到平盤下，強烈出清警訊"

    if all(p <= reference_price for p, v in buy_orders):
        buy_state = "只在平盤下，還在吃貨"
    elif any(p >= reference_price for p, v in buy_orders):
        buy_state = "擴散到平盤上/漲停，主力主導拉抬確認"
```
- **參數**: 無明確數字門檻，判讀本身是「有/無跨越平盤價」的二元邏輯，不需要額外參數。
- **可回測**: 否——資料源完全未知，無法回測。
- **信心**: 15/100 低（規則邏輯本身在書中描述得非常清楚、對稱、且有多個真實案例驗證，方法論品質很高；但扣到最低分的原因是這是全書資料需求最細的規則，連資料源是否存在都還沒查證，距離可執行的落差比其他任何一條規則都大）。
