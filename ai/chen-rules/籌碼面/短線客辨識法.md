# 短線客辨識法

- **Rule ID**: R-CHIP-16
- **名稱**: 短線客辨識法（掛單集中單一價位 vs. 主力逐價掛單）
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P06-C1-要命短線客人氣股由多翻空.md`（第6篇第1章「要命短線客 人氣股由多翻空」，p.202-205）
- **解讀**: 短線客（做隔日沖）跟主力的掛單模式有明顯差異：**短線客只集中掛單在漲停價**（其他價位都不買），目的是幫忙鎖住漲停板製造熱度；**主力則是逐價掛單**，出現賣壓就一路吃貨。書中勝華(2384)案例展示分點買張排行表格，短線券商(如嘉義富邦)大量買在漲停價位可作為判定依據。書中還提供兩個具體行動建議：(1) 收盤後分析追漲停的券商身分——如果是主力/高手券商可安心續抱，如果是短線券商則隔日逢高應先賣掉；(2) 區分鎖漲停的兩種成因——短線客自己去鎖（先賣為宜）vs. 跟著投信/主力順勢去鎖（法人隔日可能被迫繼續補買，個股可能續強），具體門檻是「今日鎖漲停股票成交張數中，若超過8成是短線客買的，就不樂觀；法人買盤較多，後勢可能續強」。
- **可程式化**: 否——判斷「掛單集中在單一價位 vs. 逐價掛單」需要當日委託/成交在各價位的張數分布，這是跟R-CHIP-12「掛單相對平盤價位置判讀系統」同一種intraday分價量明細資料，資料源完全未知，比`broker_chips`(單日買賣總量)更細一層。
- **所需資料**: 個股單一券商分點的當日分價成交明細（intraday，資料源未知）。
- **計算公式**:
```
function is_day_trader_broker(stock, trader, date):
    orders = price_volume_detail(stock, trader, date, side="buy")  # 資料源未知
    price_range = max(p for p, v in orders) - min(p for p, v in orders)
    concentrated_at_limit = all(p == limit_up_price(stock, date) for p, v in orders)
    return concentrated_at_limit  # True=短線客特徵；False(逐價分布)=較可能是主力

function limit_up_composition(stock, date, day_trader_brokers):
    total_volume = sum(broker_chips[stock][date][tr].buy for tr in all_traders)  # 待broker_chips
    day_trader_volume = sum(broker_chips[stock][date][tr].buy for tr in day_trader_brokers)
    ratio = day_trader_volume / total_volume
    return "看淡" if ratio > 0.8 else "法人買盤較多，可能續強"
```
- **參數**: 短線客占比門檻80%為書中明確數字（但仍需要分點/分價資料才能計算）。
- **可回測**: 否——資料源未到位，無法回測。
- **信心**: 20/100 低（80%門檻是明確數字，方法論邏輯也清楚；但扣到低分是因為需要的intraday分價資料完全沒有查證過來源，且即使`broker_chips`(分點單日總量)到位也不夠——需要比它更細的分價明細才能真正區分「集中在單一價位」vs「逐價掛單」）。
