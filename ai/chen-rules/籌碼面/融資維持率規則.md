# 融資維持率規則

- **Rule ID**: R-CHIP-02
- **名稱**: 融資維持率規則（斷頭警示與超跌反彈）
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P02-C4-融資維持率揭秘勿買斷頭股.md`（第2篇第4章「融資維持率揭秘 勿買斷頭股」，p.076-083）
- **解讀**: 融資維持率＝股票市值÷借款金額，是券商規則定義的硬性數字，不是統計推論。書中給出完整的三階段規則鏈(166%初始→135%警戒→120%斷頭)，並延伸出「連續數日低於120%即為超跌、可搶短線反彈」的第四階段判讀，逐條列於下：
  1. **166%初始值**：假設個股融資成數6成，剛融資買進當天維持率是100÷60=166%。
  2. **135%「爹不疼、娘不愛」警戒**：跌到這個水位時，主力會迴避這檔股票（因為有大量融資
     戶正在苦撐），對散戶來說卻容易誤判成「跌深可以撿便宜」。
  3. **120%斷頭線**：券商規則的強制賣出門檻，跌破就會觸發俗稱「斷頭」的融資強制回補賣壓。
  4. **超跌反彈**：融資維持率連續幾個交易日都在120%以下，代表斷頭賣壓已經造成「超跌」，
     反而是搶短線反彈的時機（僅適合手腳靈活、能嚴設停利的短線操作）。
  - 案例：友達(2409)2012年7月、榮化(1704)2012年10月，維持率跌破135%後一路探底到120%
    才止穩；四維航(5608)、富鼎(8261)則是維持率觸底反彈後短時間內回補超跌跌幅。
- **可程式化**: 大部分可直接程式化——TWSE官方`MI_MARGN`端點每日公告融資餘額（本專案
  `margin_trading`表已有這份資料，見下方實作進度），166%/135%/120%三個門檻數字書中
  明確給出；唯一的量化門檻缺失是「連續幾個交易日都在120%以下」才算超跌反彈訊號，書中
  沒有給精確天數，本專案用工程估計值3天頂替（見`src/indicators/margin_trading.py`的
  `OVERSOLD_MIN_CONSECUTIVE_DAYS`）。另外個股實際融資成數並非一律6成，本專案用可調參數
  `margin_pct`（預設0.6）處理，書中自己也提醒不能一律套用166%這個數字。
- **所需資料**: 個股每日融資買進/賣出/現金償還/餘額（TWSE官方`MI_MARGN`，本專案已有）、
  收盤價、（個股實際融資成數規定，目前用預設6成近似，TWSE OpenAPI未找到直接欄位）。
- **計算公式**:
```
function margin_maintenance_ratio(stock, t, margin_pct=0.6):
    # 加權平均成本法近似：融資餘額增加時用當天收盤價併入舊部位的加權平均成本，
    # 餘額減少時成本不變(賣出的部位退出，剩下部位均價不受影響)
    if today_balance <= 0:
        avg_cost = 0
    elif today_buy > 0 and today_balance > prev_balance:
        new_qty = today_balance - prev_balance
        avg_cost = (avg_cost * prev_balance + close[t] * new_qty) / today_balance
    # 餘額減少或持平：avg_cost不變
    loan_per_share = avg_cost * margin_pct
    return close[t] / loan_per_share if loan_per_share > 0 else None

function classify_state(ratio):
    if ratio < 1.20: return "已跌破斷頭線"
    if ratio < 1.35: return "警戒區(爹不疼娘不愛)"
    return "正常"

function oversold_rebound_signal(ratio_series, t, min_days=3):
    return all(ratio_series[t-min_days+1 : t+1] < 1.20)
```
- **參數**: 斷頭線120%(`MARGIN_LIQUIDATION_RATIO`)、警戒線135%(`MARGIN_WARNING_RATIO`)、
  初始融資成數預設6成(`DEFAULT_MARGIN_PCT`，書中明確承認並非所有個股都適用)、超跌反彈
  連續天數門檻3天(`OVERSOLD_MIN_CONSECUTIVE_DAYS`，書中未給精確數字，工程估計值)。
- **可回測**: 大部分可回測——166%/135%/120%三階段狀態分類可直接回測；超跌反彈訊號的
  「連續天數」門檻本身是工程估計值，回測結果對這個參數的選擇會比較敏感。
- **信心**: 85/100 高（書中形容這是「全書目前為止公式最明確、門檻數字最完整、最容易直接
  程式化的一章」，166%/135%/120%三個數字都是券商硬性規則、不是統計推論，資料來源
  （TWSE官方`MI_MARGN`）已查證可用且本專案已經接上；扣分原因：個股實際融資成數並非
  一律6成、超跌反彈的「連續幾天」門檻書中沒給精確數字，這兩點都需要工程估計值頂替，
  不是書中直接給出的硬數字）。
