# 操作模式轉變即訊號方法論

- **Rule ID**: R-CHIP-25
- **名稱**: 「操作模式轉變即訊號」方法論
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P04-C3-護盤手政府基金觀全球.md`（第4篇第3章「護盤手 政府基金觀全球」，p.153-157）
- **解讀**: 書中觀察政府基金2011~2013年操作軌跡發現：2011歐債風暴~2012年底屬於「區間操作、低買高賣」（守住陳沖防線後趁反彈賣股，證所稅利空隨指數接籌碼、利空出盡就出脫），但**2013年3月起轉為「漲也買、跌更買」**，代表對後市看法從「區間整理」轉為「長多格局」。書中評為「很有價值、可程式化的通用偵測方法」：不需要知道政府基金「說了什麼」，只需要偵測其「行為模式本身的轉變」——若一個長期只在低點買、高點賣的區間操作者，轉為不論漲跌都持續買進，這個行為模式轉變本身就是強力的長線多空判斷訊號。跟第3篇「水庫調節型」（公司派逢低買、逢高賣）的行為模式概念類似，差別在於這裡關注的是「該行為模式本身是否改變」而非「該行為模式的方向」，理論上可以抽象成適用於任何長期追蹤對象（不限於政府基金）的通用方法。
- **可程式化**: 否——核心是要先能區分「區間操作(逢低買逢高賣)」vs「不論漲跌都買」這兩種行為模式，需要長期(至少橫跨1個以上完整價格週期)的個股×特定機構(券商分點)交易史（`broker_chips`表，待FinMind付費方案），且需要先鎖定要追蹤的對象（如R-CHIP-24的5家代理券商，或其他被驗證過的長期主力）才能套用這個方法。
- **所需資料**: 特定機構/券商分點的長期買賣歷史（`broker_chips`表，待FinMind付費方案，需要橫跨完整價格週期的資料）、股價（已有，用於區分「低點」「高點」）。
- **計算公式**:
```
function classify_trading_pattern(trader, stock, period_start, period_end, price_percentile_low=0.3, price_percentile_high=0.7):
    trades = broker_chips[stock][trader][period_start:period_end]  # 待broker_chips
    price_pcts = [price_percentile(stock, t.date) for t in trades]
    buys_at_low = sum(1 for t, p in zip(trades, price_pcts) if t.buy > t.sell and p < price_percentile_low)
    buys_at_high = sum(1 for t, p in zip(trades, price_pcts) if t.buy > t.sell and p > price_percentile_high)
    if buys_at_high > 0 and buys_at_low > 0 and buys_at_high / (buys_at_low + buys_at_high) > 0.4:
        return "不論漲跌都買，行為模式轉為長多格局"
    return "區間操作，逢低買逢高賣"

function pattern_shift_signal(trader, stock, t, lookback_period, recent_period):
    old_pattern = classify_trading_pattern(trader, stock, *lookback_period)
    new_pattern = classify_trading_pattern(trader, stock, *recent_period)
    if old_pattern != new_pattern:
        return f"{trader}操作模式從「{old_pattern}」轉為「{new_pattern}」，值得留意"
```
- **參數**: 「低點/高點」的價格分位數門檻、「不論漲跌都買」的判定比例(0.4)都是本專案的工程估計，書中沒有給出精確數字。
- **可回測**: 否——資料源未到位，且需要橫跨完整價格週期的歷史資料才能做有意義的模式分類，短期內無法回測。
