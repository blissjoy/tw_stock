# 已驗證主力資金轉移追蹤

- **Rule ID**: R-CHIP-19
- **名稱**: 已驗證準確度主力的資金轉移追蹤
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P07-C2-看好緯創主力下重本撐腰.md`（第7篇第2章「看好緯創 主力下重本撐腰」，p.234-238）
- **解讀**: 與R-CHIP-13「換券商出貨偵測」裡的黑松→農林案例同類型，但這裡是從「主力自己的正常操作節奏」（非經營權之爭出脫）觀察，更具通用性：`(某主力對股票A的歷史操作被驗證長期準確) + (該主力從股票A撤出大筆資金且遲遲不回補) + (該資金整筆轉入股票B)` → 股票B可能具備一般投資人不知道的營運利多。可成→緯創案例：可成台南主力2011年賣出5.5萬張後只接回2萬多張、手頭資金明顯充裕，2013年7月一口氣買進緯創6萬多張，後續緯創股價確實強勢表態。書中同時提醒兩個操作紀律：(1) 水庫調節型主力可再細分「果決賣壓型」(高檔一次大量賣、低檔一次大量接)與「溫和收放型」(逐步慢慢收放)，可用單筆交易量占比區分；(2) 跟單前需確認自己的交易頻率是否與主力操作風格(通常是極長線)匹配，否則容易在等待中失去耐性。
- **可程式化**: 否——核心前提是需要「長期(數年)的個股-券商分點交易史」才能先建立「這個主力歷史操作是否準確」的驗證資料庫，再監控其資金流向。這比R-CHIP-13「換券商出貨」需要的資料時間跨度更長（要橫跨多年、多檔股票才能建立「主力準確度」的信譽評分），資料源同樣卡在`broker_chips`（待FinMind付費方案），且需要額外的長期歷史累積時間，即使拿到付費方案也需要時間累積才能用。
- **所需資料**: 個股每日各券商分點買賣張數（`broker_chips`表，待FinMind付費方案，且需要長達數年的歷史累積）。
- **計算公式**:
```
function track_verified_trader_fund_flow(trader, stock_universe, t):
    trader_track_record = compute_historical_accuracy(trader, stock_universe)  # 需要多年跨股票歷史
    if trader_track_record < min_accuracy_threshold:
        return None
    for stock_a in stocks_trader_recently_exited(trader, t, lookback=180):
        if not has_rebought(trader, stock_a, t):
            for stock_b in stocks_trader_recently_entered(trader, t, lookback=30):
                return f"{trader}可能將資金從{stock_a}轉往{stock_b}，值得留意"
```
- **參數**: 「歷史準確度」的評分方法與門檻書中沒有給出量化定義，需自行設計並回測；「遲遲不回補」的觀察期間也沒有精確天數。
- **可回測**: 否——資料源未到位且需要長期歷史累積，短期內無法回測。
- **信心**: 20/100 低（方法論本身有價值、且跟R-CHIP-13可以共用部分基礎設施；但這是本清單中對歷史資料時間跨度要求最長的規則之一，即使`broker_chips`未來付費解鎖，也需要額外等待數年累積才能真正建立「主力信譽評分」，短中期都難以落地）。
