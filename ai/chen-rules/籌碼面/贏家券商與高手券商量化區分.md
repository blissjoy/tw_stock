# 贏家券商與高手券商量化區分

- **Rule ID**: R-CHIP-30
- **名稱**: 贏家型主力辨識法（贏家券商 vs. 高手券商量化區分）
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P03-C5-贏家型出手勝率大.md`（第3篇第5章「贏家型 出手勝率大」，p.122-126）
- **解讀**: 5大主力分類最後一類。贏家券商低調不為人知，不侷限單一個股，不分傳產股或電子股，只要出手勝率就奇高。跟高手券商(R-CHIP-28)的分類邊界：贏家券商不見得是股價主導者，比較像「跟單者」而非主控者，操作風格是中線操作、只賺魚身；高手券商較常以主導者角色出現、且是個股專屬。**量化區分邏輯**：同一券商在多檔不同股票上勝率都高＝贏家券商；勝率高但集中在單一/少數個股＝高手券商。這需要跨股票、長期的券商損益統計資料才能建立。重要跟單邏輯：**「高手券商出場」警示意味強**（主導者離場代表對個股掌握判斷改變），**「贏家券商出場」不一定代表股價見頂**（只是跟單者獲利了結或風險考量，不代表股價漲完了）——程式化「主力出場預警」規則時必須先區分券商類型，不能一視同仁。書中列出2014年市場上至少30家贏家券商及10家台北分點具名清單，但明確提醒這是2014年的靜態名單，可能已隨券商整併(如元大寶來已合併)、主力更換而失效。
- **可程式化**: 否——需要跨股票、長期(數年)的券商損益統計資料，才能計算「同一券商在多檔股票上的歷史勝率」並區分贏家vs高手券商，資料源是`broker_chips`表（待FinMind付費方案），且資料需求時間跨度是本清單最長的之一（要橫跨足夠多檔股票、足夠長時間才能形成有統計意義的勝率）。書中2014年具名清單因時效性問題（券商整併、主力更換）不建議直接套用，只能當歷史參考範例。
- **所需資料**: 個股×券商×長期歷史買賣與損益（`broker_chips`表，待FinMind付費方案，需橫跨多檔股票、多年歷史）。
- **計算公式**:
```
function broker_win_rate_across_stocks(trader, stock_universe, years=3):
    results = []
    for stock in stock_universe:
        episodes = extract_trading_episodes(stock, trader, years)  # 待broker_chips
        for ep in episodes:
            results.append(ep.pnl > 0)
    win_rate = mean(results)
    distinct_stocks_involved = count(distinct stock for stock, ep in results if ep.pnl != 0)
    return win_rate, distinct_stocks_involved

function classify_broker_type(trader, stock_universe):
    win_rate, distinct_stocks = broker_win_rate_across_stocks(trader, stock_universe)
    if win_rate > high_win_rate_threshold:
        return "贏家券商(多檔股票勝率皆高)" if distinct_stocks >= min_stocks_for_winner else "高手券商(集中單一/少數個股)"
    return "普通券商"

function exit_warning_weight(broker_type):
    return "高" if broker_type == "高手券商" else "低"  # 高手出場警示強，贏家出場不一定代表見頂
```

- **可回測**: 否——資料源未到位，且需要橫跨多檔股票、多年的歷史資料才能形成有統計意義的分類，短期內無法回測。
- **信心**: 15/100 低（「高手出場vs贏家出場」的跟單邏輯區分是本篇重要的方法論提醒，值得記錄；但這是全書資料需求時間跨度最長的規則之一，需要`broker_chips`橫跨多年多股的完整歷史才能建立有意義的勝率統計，且書中具名清單已因時效性問題不可直接使用，距離可執行還很遠）。
