# 分點參與率

- **Rule ID**: R-CHIP-08
- **名稱**: 分點參與率
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P02-C3-分點參與率看穿散戶動態.md`（第2篇第3章「分點參與率 看穿散戶動態」，p.068-074）
- **解讀**: 分點參與率＝該股票當日/當期有實際交易紀錄的券商分點數 ÷ 全台總券商分點數（約1,000+家）。主力再怎麼分散開戶頂多20家，只占全台券商據點不到2%，只有散戶才會分散在全省各地，所以分點參與率越高代表散戶參與比重越多。判讀規則：(1) 分點參與率剛開始往上走＝多頭訊號，代表散戶開始跳進來、股價通常會跟著漲一段；(2) 分點參與率創個股自身歷史新高＝過熱警訊，代表能買的散戶都買了，續航力不樂觀，精明主力反而會趁此時出貨；(3) **必須跟個股自身歷史比較，不可跨股票比較絕對值**（大型股本身參與率就可能高達90%以上，小型冷門股可能只有20~30%）。本章開頭還有一段重要修正：**融資已經不再是純散戶指標**——現在主力大戶也大量使用融資鎖籌碼，之後任何用融資水位推論散戶行為的規則都要考慮這個轉變。
- **可程式化**: 否——公式本身簡單明確(`該股當日有交易的券商分點數 / 全台總券商分點數`)，但分子「該股當日有交易的券商分點數」需要逐日的個股×券商分點交易明細，這就是`broker_chips`表的資料（FinMind`TaiwanStockTradingDailyReport`），目前需要FinMind付費(Sponsor)方案才能呼叫，本專案`fetch_broker_chips()`函式已寫好但未啟用（見`src/data/finmind_client.py`）。分母「全台總券商分點數」可用`securities_traders`表（已有，免費）算出。
- **所需資料**: 個股每日各券商分點交易明細（`broker_chips`表，待FinMind付費方案）、全台券商分點總數（`securities_traders`表，已有）、個股歷史分點參與率（用於跟自身歷史比較，需先有上述資料才能累積）。
- **計算公式**:
```
function branch_participation_rate(stock, date):
    active_branches = count(distinct securities_trader_id
                             for row in broker_chips
                             if row.stock_id == stock and row.date == date)
    total_branches = count(securities_traders)
    return active_branches / total_branches

function is_at_historical_high(stock, t, lookback_days):
    series = [branch_participation_rate(stock, d) for d in last(lookback_days, t)]
    return series[-1] >= max(series)  # 創個股自身歷史新高
```
- **參數**: 「歷史新高」的回顧窗口書中未給精確天數，需自行決定並回測。
- **可回測**: 否——資料源未到位，無法回測。
