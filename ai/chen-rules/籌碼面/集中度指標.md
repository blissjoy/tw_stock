# 集中度指標

- **Rule ID**: R-CHIP-11
- **名稱**: 分點集中度指標（買賣盤集中度差值）
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P02-C5-集中度股票漲勢的關鍵.md`（第2篇第5章「集中度 股票漲勢的關鍵」，p.084-093）
- **解讀**: 書中評為「與第2章並列全書最高」評級，是全書唯一給出明確數值定義域的指標：集中度∈[0,1]，1＝所有進出全集中在單一券商，0＝均勻分散在全台1,000多家券商。每天分別算「買進集中度」與「賣出集中度」，**差值(買進集中度－賣出集中度) ≥ +0.15＝買盤積極；≤ -0.15＝賣壓大**。連續性比單日數值更重要——出現連續紅色(買)或連續綠色(賣)才代表「持續加碼/減碼」有意義；差值可累計，若差值開始走平代表主力一邊拉一邊出，不是好現象。書中沒有給出精確數學公式，本筆記推測極可能是Herfindahl指數(HHI)：對N個券商分點的成交量占比計算Σ(市占率²)，單一券商壟斷時HHI=1，均勻分散在N家(N≈1,000)時HHI≈1/N≈0.001，數值上跟書中兩個邊界條件吻合，但這只是推論，需要用書中p.088台泥實例數據（0.82、0.86等）回頭驗證校準。書中還展示「集中度＋高手券商＋羊群指標」三指標疊加是全書對「多指標組合判斷」最具體的示範。
- **可程式化**: 否——公式推論（HHI）本身不難寫，但需要「每日各券商分點的買賣張數明細」（`broker_chips`表），跟R-CHIP-08「分點參與率」、R-CHIP-09「假外資偵測」是同一個資料瓶頸（FinMind付費方案），目前完全無法計算，也無法用台泥實例數據驗證HHI推論是否正確。
- **所需資料**: 個股每日各券商分點買/賣張數（`broker_chips`表，待FinMind付費方案）。
- **計算公式**:
```
function concentration_hhi(rows_for_side):  # side = 買 or 賣
    total = sum(row.volume for row in rows_for_side)
    if total == 0:
        return 0
    return sum((row.volume / total) ** 2 for row in rows_for_side)

function concentration_diff(stock, date):
    buy_rows = [r for r in broker_chips[stock][date] if r.buy > 0]
    sell_rows = [r for r in broker_chips[stock][date] if r.sell > 0]
    diff = concentration_hhi(buy_rows) - concentration_hhi(sell_rows)
    if diff >= 0.15: return "買盤積極"
    if diff <= -0.15: return "賣壓大"
    return "無明確訊號"
```
- **參數**: 差值門檻±0.15為書中明確數字；「近15個交易日集中度為正/負」的排行窗口、「5至15天」的觀察期間書中都只是舉例參考值，未解釋為何選這個區間，需自行回測驗證。HHI公式本身也是本專案的推論，需要用書中台泥範例數據校準才能確認正確性。
- **可回測**: 否——資料源未到位，且HHI公式本身尚未驗證是否符合書中定義，無法回測。
- **信心**: 35/100 低（±0.15門檻是書中明確給出的硬數字，理應不低；但扣分原因有兩個：一是`broker_chips`資料源未到位完全無法計算，二是集中度的精確數學公式書中沒有給、本專案的HHI推論還沒有機會用實例數據驗證，存在「連公式本身對不對都不確定」的風險）。
