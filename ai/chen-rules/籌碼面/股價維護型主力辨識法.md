# 股價維護型主力辨識法

- **Rule ID**: R-CHIP-26
- **名稱**: 股價維護型主力辨識法
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P03-C1-股價維護型進出頻繁.md`（第3篇第1章「股價維護型 進出頻繁」，p.096-101）
- **解讀**: 5大主力分類之一。股價維護者首要任務是維持個股一定流動性，避免成交量冷掉被市場遺忘，通常受公司委託或有默契，會持續進出並釋放消息創造成交量，不一定要拉股價大漲。辨識規則：(1) 篩選「股價在一段長時間內（如2年）價格差異不大」的個股(區間震盪/報酬率接近0/波動率偏低)；(2) 對該股所有交易券商分點逐一計算「區間損益」(買進張數×買進均價 vs 賣出張數×賣出均價的差額)；(3) 若多數券商損益打平或虧損，但某一家券商損益特別突出（且是「進出頻繁中賺錢」而非「長期單邊布局」），該券商極可能是股價維護型主力。久元(6261)案例：2年多股價原地踏步，多數券商小賺小賠甚至外資都僅小賺，唯獨日盛大墩淨賺近3,000萬元且進出頻繁。操作建議：可跟進但停利要快，因為此類主力目的不是拉股價。
- **可程式化**: 否——需要「個股×券商分點×買進均價/賣出均價/張數」的細顆粒度資料，比單純的分點參與率/集中度（只需要「有無交易」）需要更多欄位，是全書對資料需求層級最高的分類之一，資料源是`broker_chips`表（待FinMind付費方案），且需要均價計算能力（`broker_chips`表本身有`price`欄位，理論上支援，但需要額外開發區間損益計算邏輯）。
- **所需資料**: 個股每日各券商分點買賣張數與成交價位（`broker_chips`表，待FinMind付費方案）、個股股價區間波動率（已有，用於篩選候選個股）。
- **計算公式**:
```
function is_range_bound(stock, start, end, volatility_threshold=0.15):
    period_return = (close[stock][end] - close[stock][start]) / close[stock][start]
    return abs(period_return) < volatility_threshold

function trader_period_pnl(stock, trader, start, end):
    rows = broker_chips[stock][trader][start:end]  # 待broker_chips
    buy_cost = sum(r.buy * r.price for r in rows)
    sell_proceeds = sum(r.sell * r.price for r in rows)
    buy_qty = sum(r.buy for r in rows)
    sell_qty = sum(r.sell for r in rows)
    return sell_proceeds - buy_cost if buy_qty > 0 and sell_qty > 0 else None

function identify_price_maintainer(stock, start, end):
    if not is_range_bound(stock, start, end):
        return None
    all_pnl = {tr: trader_period_pnl(stock, tr, start, end) for tr in all_traders(stock, start, end)}
    outlier = max(all_pnl, key=all_pnl.get)
    trading_frequency = trading_days_count(stock, outlier, start, end) / (end - start)
    if all_pnl[outlier] > outlier_profit_threshold and trading_frequency > frequent_threshold:
        return outlier
```

- **可回測**: 否——資料源未到位，無法回測。
