# 投信連續買超觀察

- **Rule ID**: R-CHIP-01
- **名稱**: 投信連續買超觀察
- **分類**: 籌碼面
- **原文與頁碼**: `ai/ebook-summary-chen/P04-C2-風向球投信動向幫抬轎.md`（第4篇第2章「風向球投信動向幫抬轎」，p.142-149）
- **解讀**: 三大法人中，投信的動向最值得追蹤跟單——投信受法規限制（單一個股持股比重不得超過基金總部位10%、單日買進不得超過該股當日成交量10%），造就「必須分批布局」的規律性，正好符合投資人跟單需求。書中完整規則鏈涵蓋分批布局節奏、切入時機、搭配大盤環境、防禦訊號、金額優先於張數、外資投信方向不一致時的判讀，逐條列於下：
  1. **分批布局節奏**：典型模式是先買2%，確認方向後再加碼3%、3%，最看好可到8%——持股
     比重上限10%、單日買進上限（成交量10%）都是具體法規數字。
  2. **切入時機**：投信連續加碼3~5天，且該股剛脫離下跌後的平盤整理、準備突破關鍵價位，
     是最佳切入點。
  3. **搭配大盤環境**：多頭時期投信加碼股漲幅可達大盤的2倍；空頭時期投信持股跌幅通常
     比大盤更深，且投信有最低持股限制（股票型基金7成、平衡型基金3~5成），這個規則要
     搭配整體行情判讀。
  4. **防禦訊號**：投信轉向買超防禦型持股（例如電信三雄）代表對後市看淡。
  5. **金額優先於張數**：媒體慣用「買賣超張數」排行是錯誤示範，應該用「買賣超金額」排序
     ——基金經理人下單看的是資金分配，不是張數。
  6. **外資投信方向不一致時**：不需要判斷孰對孰錯，靜待股價表態即可（中小型股仍以投信
     較可信）。
  - 案例：聚陽(1477)2011年11月投信連續買超後大漲，其中2011/11/30單日成交量472張裡有
    348張(73.7%)是投信買進；敬鵬(2355)、華夏(1305)同樣符合「投信連續買超後大漲」。
- **可程式化**: 部分——第1項（分批布局節奏2%→3%→3%→8%）跟第2項（連續3~5天門檻）是
  具體法規/天數數字，可直接程式化；第3項（搭配大盤多空環境）需要額外的大盤趨勢判斷
  （可參考`ai/zhu-rules/趨勢判定`既有規則）；第4項（防禦股清單）書中僅舉例、沒有給
  判定標準，需要自建/維護一份防禦性股票清單才能程式化；第5項（金額排序）是方法論修正，
  純粹是資料處理時該用哪個欄位排序，不是觸發條件；第6項（方向不一致時看股價表態）是
  事後驗證邏輯，不是「觸發即報」性質的訊號。
- **所需資料**: 投信每日買進/賣出（張數與金額）、個股當日成交量、大盤趨勢狀態、（防禦股
  清單，目前無資料來源）。
- **計算公式**:
```
function investment_trust_buy_streak(stock, t):
    # 連續買超天數：從t往回數，投信買賣超淨額(買進-賣出)同方向且為正的天數
    streak = 0
    for day in reversed(days_up_to(t)):
        net = investment_trust_buy[day] - investment_trust_sell[day]
        if net <= 0:
            break
        streak += 1
    return streak

function is_buy_watch(stock, t, threshold=3):
    return investment_trust_buy_streak(stock, t) >= threshold
```
- **參數**: 連續買超天數門檻3天（書中給3~5天區間，本專案採下限3天，見
  `src/indicators/institutional_flow.py`的`INSTITUTIONAL_STREAK_THRESHOLD`）；
  持股比重上限10%、單日買進上限（成交量10%）、分批布局節奏2%→3%→3%→8%這三項法規
  數字目前程式碼尚未使用（只用了「連續買超天數」這一個子條件）。
- **可回測**: 部分——「連續買超天數」子條件本身可回測；完整規則鏈（含「剛脫離下跌整理」
  「大盤多空環境」等條件）需要額外資料/判斷才能組合回測，目前只回測/驗證了單一子條件。
- **信心**: 80/100 中高（書中用整整一章給出多組具體法規數字與天數區間，是全書「法規數字
  最密集、最具體可程式化」的一章，跟R-SCREEN-06同屬「書中逐條列出、附反面案例」的高品質
  等級；但目前程式碼只實作了規則鏈裡「連續買超天數」這一個子條件，其餘子條件（分批布局
  比例追蹤、金額排序、防禦股清單、大盤環境搭配）都還沒程式化，這是相對於R-SCREEN-06
  多扣5分的原因——書本身的具體程度給滿分等級，但目前的「可程式化完整度」還沒有跟上）。
