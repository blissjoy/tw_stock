# 法人買賣超N日張數合計

- **Rule ID**: R-HUANG-02
- **名稱**: 法人買賣超N日張數合計
- **分類**: 籌碼面
- **程式碼來源**: private
- **解讀**: 把投信/外資最近N天的(買進-賣出)淨額加總，除以1000換算成「張」，四捨五入到整數。分別對40日、20日、10日、5日四種天期各自計算，投信/外資各一組，共8個數字。資料筆數不足N天時，直接用現有多少筆就加總多少筆，不會因為資料不足而留白或報錯。
- **可程式化**: 是
- **所需資料**: 每日投信/外資買賣超明細(股數)
- **計算公式**:
```
function sum_institutional_flow_lots(net_values_desc, n):
    return round(sum(net_values_desc[:n]) / 1000)
```
- **參數**: 天期固定40/20/10/5日四組
- **可回測**: 未評估——純粹是資料加總換算，沒有另外驗證這個天期組合的實戰有效性
- **信心**: private
