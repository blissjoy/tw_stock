# 投信外資連續買賣超狀態判讀

- **Rule ID**: R-HUANG-01
- **名稱**: 投信外資連續買賣超狀態判讀
- **分類**: 籌碼面
- **程式碼來源**: private
- **解讀**: 從最新一天的法人買賣超淨額(買進-賣出)開始往回看，判斷目前是「連續同方向N天」還是「剛從一段反方向的行情翻轉過來」。同方向連續天數N達到3天以上，直接顯示「連買N天」/「連賣N天」；未達3天時，再往前檢查前一段反方向的連續天數M，M達到3天以上顯示「連M賣後轉買」/「連M買後轉賣」，否則顯示「方向未定」；當天淨額剛好是0另外顯示「持平」。投信、外資(僅計FinMind的Foreign_Investor，不含Foreign_Dealer_Self)各自套用同一套判讀。
- **可程式化**: 是（本身已經是逐行程式碼，非文字敘述轉譯）
- **所需資料**: 每日三大法人買賣超明細(投信/外資買進/賣出股數)
- **計算公式**:
```
function classify_institutional_streak(net_values_desc):
    # net_values_desc：依日期新到舊排序的每日(買-賣)淨額，index 0是最新一天
    dirs = [sign(v) for v in net_values_desc]  # 1=買超, -1=賣超, 0=打平
    if dirs[0] == 0: return "持平"
    today_dir = dirs[0]
    N = count_leading_same_direction(dirs, today_dir)
    if N >= 3 or 沒有更早的歷史可比對:
        return f"連買{N}天" if today_dir==1 else f"連賣{N}天"
    if dirs[N] == 0:
        return "方向未定"
    M = count_leading_same_direction(dirs[N:], dirs[N])
    if M >= 3:
        return f"連{M}賣後轉買" if today_dir==1 else f"連{M}買後轉賣"
    return "方向未定"
```
- **參數**: 連續天數確認門檻固定3天(N與M共用同一個門檻)
- **可回測**: 未評估——目前只是原封不動複製現成邏輯，沒有backtest佐證這些門檻/判讀方式的實戰有效性
