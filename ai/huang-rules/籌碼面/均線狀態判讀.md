# 均線狀態判讀

- **Rule ID**: R-HUANG-03
- **名稱**: 均線狀態判讀
- **分類**: 籌碼面
- **程式碼來源**: private
- **解讀**: 比較「今天的MA20」跟「前一個交易日的MA20」，數值持平或變大視為「上揚」，變小視為「下彎」；MA60同理。收盤價本身也一併列入比較，是否為紅K(收盤價>=開盤價)決定顯示顏色。三項(MA20狀態、MA60狀態、收盤價)依數值大小由大到小排序決定顯示順序。
- **可程式化**: 是
- **所需資料**: 每日收盤價、MA20、MA60(本專案直接沿用`daily_indicators`既有算好的均線值，不重新從K線計算)
- **計算公式**:
```
function classify_ma_price_position(ma20_today, ma20_yesterday, ma60_today, ma60_yesterday, close_today, open_today):
    ma20_up = ma20_today >= ma20_yesterday
    ma60_up = ma60_today >= ma60_yesterday
    is_red_k = close_today >= open_today
    items = [("MA20", ma20_today, ma20_up), ("MA60", ma60_today, ma60_up), ("P", close_today, is_red_k)]
    return sort_desc_by_value(items)
```
- **參數**: 均線天期固定20/60日，比較基準固定「今天 vs 前一交易日」(單日斜率，非多日趨勢)
- **可回測**: 未評估
- **信心**: private
