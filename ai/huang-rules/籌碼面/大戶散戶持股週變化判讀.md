# 大戶散戶持股週變化判讀

- **Rule ID**: R-HUANG-05
- **名稱**: 大戶散戶持股週變化判讀
- **分類**: 籌碼面
- **程式碼來源**: private
- **解讀**: 取集保戶股權分散表裡資料實際存在的最新兩個公告日期(這份資料週更新，不是每個交易日都有新的一筆)，比較「大戶」(僅計1000張以上這一個級距的持股%)、「散戶」(加總9個小級距，1~999股到50,001~100,000股，中間5個級距不算大戶也不算散戶)兩者的持股百分比差異。依|差異|大小分四級：>=2%「爆買/爆賣」、>=1%「大增/大減」、>=0.5%「增持/減持」、其餘「小增/小減」。大戶增持顯示紅色、減持綠色；散戶則相反(增持綠色、減持紅色，因為散戶進場常被當反指標)。
- **可程式化**: 是
- **所需資料**: 集保戶股權分散表(FinMind TaiwanStockHoldingSharesPer)，每個持股級距的百分比
- **計算公式**:
```
function classify_holder_change(rows_by_date):
    dates = sorted(rows_by_date.keys(), reverse=True)
    if len(dates) < 2: return None
    latest, prev = dates[0], dates[1]
    whale_diff = round2(whale_pct(latest) - whale_pct(prev))
    retail_diff = round2(retail_pct(latest) - retail_pct(prev))
    return {
        "whale": tier_label(whale_diff, increase_color=紅, decrease_color=綠),
        "retail": tier_label(retail_diff, increase_color=綠, decrease_color=紅),
    }
```
- **參數**: 分級門檻±2%/±1%/±0.5%；大戶級距="more than 1,000,001"；散戶級距見上方解讀欄列出的9個區間
- **可回測**: 未評估
- **信心**: private
